# Premium Next.js Personal Portfolio

A modern, high-performance personal portfolio website built with **Next.js 14**, **Tailwind CSS**, and **Framer Motion**. Featuring smooth animations, dark mode support, responsive design, and SEO optimization.

## 🌟 Features

### Core Features
- ✨ **Modern, Premium Design** - Clean, minimal, and visually impressive layout
- 🎨 **Dark Mode & Light Mode** - Built-in theme toggle with persistence
- 📱 **Fully Responsive** - Mobile-first design that works on all devices
- ⚡ **High Performance** - Optimized images, lazy loading, and fast load times
- 🎬 **Smooth Animations** - Scroll reveal, hover effects, and transitions using Framer Motion
- 🎯 **SEO Optimized** - Meta tags, Open Graph, semantic HTML, and structured data
- ♿ **Accessibility** - ARIA labels, semantic markup, and keyboard navigation

### Sections
- **Hero** - Eye-catching introduction with CTA button
- **About** - Personal description and background
- **Skills** - Organized skills display with progress bars
- **Projects** - Responsive grid showcase with GitHub and live demo links
- **Contact** - Contact form with validation and social links
- **Footer** - Quick links and social media integration

### Additional Features
- 🧭 **Sticky Navbar** - Smooth scrolling navigation
- 📊 **Scroll Progress Indicator** - Visual scroll position tracker
- 📥 **Resume Download** - Direct download button
- 🔗 **Social Integration** - GitHub, LinkedIn, Twitter, Email links
- 💾 **Form Validation** - Client-side form validation with error messages
